Identify the command method that creates a Click context for a command-line
invocation, applies extra context settings, and delegates argument processing
before returning the initialized context.

Mandatory native protocol:
1. First run a shell command that prints the working directory and Git root,

2. Use only current-repository shell inspection; no MCP, web, external docs, or
   prior knowledge.
3. Inspect completed search output, then read the strongest candidate's entire

4. Every reported symbol and range must have a successful command naming the
   relative file and emitting all numbered lines.
5. Use the last syntax line as `end_line`, excluding blank separators.
6. Do not modify files. On a required command failure, return
   `INFRA_ERROR: native_search_failed`.

Return `primary` with its symbol, relative file, and exact range. Return
`related` as zero or one verified symbol with `relationship` set to `caller`
or `callee`, plus its relative file and exact range; use one when available.
Give a concise boundary explanation using the supplied JSON schema.

Report every `file` value as the path relative to the root of the repository you were given. Do not prefix it with the upstream project's directory layout.
